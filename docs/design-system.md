# 分身工作台视觉基准

- 基准画布：1440×960，macOS 桌面应用。
- 布局：首页为 240px 左侧栏、开放主内容、约 300px 活动栏；PPT 页面为左侧栏、190px 流程栏、弹性画布、310px 审批栏。
- 颜色：纯白/冷中性背景，石墨正文，蓝紫色主强调，成功状态使用克制绿色；无装饰性渐变和辉光。
- 字体：`Inter`, `PingFang SC`, `Microsoft YaHei`, sans-serif；标题 28–32px，正文 14–16px，控制文字 13–14px。
- 容器：开放画布、细分隔线和列表行；只在真正需要层级时使用轻微圆角和阴影。
- 图标：统一细线轮廓，16–20px，使用 `currentColor`。
- 动效：150–220ms，尊重 `prefers-reduced-motion`。
- 首页首屏允许文案：分身工作台、首页、通用任务、PPT 项目、审批中心、偏好记忆、设置、早上好，今天从哪里开始？、新建 AI 任务、创建 PPT 项目、最近工作、待处理审批、Codex 连接状态。
- PPT 工作台允许核心文案：材料、材料分析、大纲审批、逐页细化、视觉审批、可编辑转换、质量检查、重新生成、批准并生成下一页、导出。
