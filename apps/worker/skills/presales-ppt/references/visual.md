# Visual stage

Design the complete slide, not a background-only image. The requested composition includes its intended hierarchy, approved visible content, diagrams, people or setting when relevant, and their spatial relationships.

- Use the project's fixed palette and template as the color authority. Do not substitute default blue/red branding or an upstream house style.
- Select a relational composition from the approved page design: layers for architecture, connected modules for an overview, a dominant scene plus functional callouts for a function page, or a directional storyboard/flow for role handoffs.
- Render approved visible text once. Scene nodes and callouts point to approved text bindings; never generate a second paraphrased set of body or diagram labels.
- Omit speaker notes, recovery notes, missing-evidence analysis, and unapproved long-form material from the image payload.
- Use reference images only for their approved purpose, such as subject, composition, or style. They are not evidence for new facts or permission to override the project palette.
- Preserve visible pending-confirmation questions as approved content. Do not convert them into confident claims.

Return a reviewable full-slide result. Do not auto-approve it and do not retry through another API or paid service when the configured generation route is unavailable.
